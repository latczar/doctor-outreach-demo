Start here

This tool turns a raw research list into a checked list of doctors, writes a personal email for each one, and sends only what a person approves.

  1. Rules check the list. Copies of the same doctor are merged. Then each doctor must fit the campaign, have a verified email, and not have been contacted recently. Plain rules make these decisions.
  2. The system writes an email for each doctor on the final list. Every draft is checked before you see it.
  3. You approve each email, edit it, or reject it. Nothing is sent without your name against it.
  4. Approved emails are sent once and logged, so nobody is contacted twice by mistake.
