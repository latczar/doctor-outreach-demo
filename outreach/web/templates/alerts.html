How an alert gets there

  1. Something urgent happens: a profile tries to give the system instructions, or an approved email fails to send.
  2. The app sends one small message to a web address, set in ALERT_WEBHOOK_URL. {% if webhook %}This copy has one set, so alerts go there.{% else %}This copy has none set, so alerts are written to outbox/alerts.log instead.{% endif %}
  3. n8n or Zapier passes it on to a Slack or Teams channel, or a WhatsApp group. Changing the chat app means changing that step, not the code.
